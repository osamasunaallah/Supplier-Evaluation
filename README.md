# Supplier Scorecard

![Supplier Scorecard](thumbnail.png)

A formula-driven supplier performance scorecard in Excel. Pick a supplier and see what was ordered, total spend, items received and real delivery lead time.

**Live case study:** https://osamasunaallah.github.io/Supplier-Evaluation/

## What it does
- Merges PO lines and cash purchases into one table
- Shows 5 live KPIs per supplier: lines ordered, total spend (incl. VAT, per currency), items received, average delivery days and last PO date
- Measures delivery days from PO date to received date
- Maps supplier name variants to one official name

## Built with
Excel dynamic arrays: LET · FILTER · VSTACK · HSTACK · SCAN · MAP · LAMBDA. No macros.

> This repository is a portfolio showcase. All data shown is placeholder data. No company information is included.
